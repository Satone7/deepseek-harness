1. 上游更新日志（按主题）

1.1 RPC / 连接层大重构（本窗口最大主线）

ApiProxy 包整体退役：refactor(api): remove ApiProxy package 及前置系列把 settings、credentials、directory-picker 等 RPC 从通用代理迁移到各域 Remote 控制器（api-gateway、session-controller、workspace-controller），transport 契约收进 connection 包自身（own RPC transport contracts），并注册精确 Fetch 路由。Host 事实（账号 home、原生打开能力等）改由 generation 携带（carry Host facts with generations）。

与 fork 面的交互：fork 的 apiproxy 非安全上下文 RPC id 修复随包消亡；其问题域（浏览器侧 id 生成）由上游 dsh-util-crypto（getRandomValues 实现 + no-restricted-properties lint 强制全仓替换）与 connection 内置 browser-safe random-uuid.ts 原生解决——fork 的 @deepseek-ai/dsh-random-uuid 包退役。

1.2 浏览器鉴权（用户可见 Breaking）

Web GUI 改为一次性 token URL 鉴权：dsh web 启动打印带进程 token 的 URL，浏览器首次访问换取签名会话 cookie（默认 30 天，cookieMaxAgeDays 可配），重定向到干净根 URL；裸 URL 一律 401。Host/Origin 栅栏仍在（防 DNS rebinding），但鉴权与可达性明确分层——上游 JSDoc：网络可达性归部署层，栅栏不是认证。

⚠️ 用户须知：服务重启后打印新 token URL（journalctl 可查）；浏览器已有会话 cookie 在有效期内免 token 直访。详见第 7 节。

1.3 CLI 与栅栏语义

  • --host 0.0.0.0 被 CLI 以安全理由拒绝（"intentionally not supported yet"）；但 webserver config 层仍接受该值，且 bind-all 时自动把本机所有非 internal IPv4 字面量加入 /api 信任面（LAN IP 直访放行）。
  • --trusted-host 保持（host 或 host:port authority，可重复）。
  • Agent Presets 从 apps/cli/config/agent-presets/ 迁至 packages/preset/agent-presets/presets/。

1.4 webserver 注入与客户端 bundle 聚合

页面注入改为结构化 IndexInjection 行 + webserver/index-inject 事件（global/script/script-src/style 行），tapIndex 降为 escape hatch。客户端插件 bundle 改经 /plugins/??pkg1/client.js,pkg2/client.js&rev=… 聚合端点按启动图组合服务，单包 /plugins/<id>/client.js 不再单独服务（未登记组合 404）。
