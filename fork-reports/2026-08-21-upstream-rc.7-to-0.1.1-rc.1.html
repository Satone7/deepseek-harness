三、附带发现：官方构建 profile

upstream 本轮引入了客户端构建档位机制：pnpm run build 默认产出「本地档」，浏览器侧品牌插件休眠（侧栏显示「DSH Local Build」）；CI 与发布用 DSH_BUILD_CLIENT_PROFILE=official 产出「官方档」，注入品牌、标题与提交哈希三个公开值。本轮已用官方档重新构建并重启 dsh-web.service，当前服务即官方档产物。

# 官方档（品牌 + 提交哈希；与 CI/test:web 期望一致）
DSH_BUILD_CLIENT_PROFILE=official pnpm run build

# 本地档（默认；侧栏显示 DSH Local Build + 提交哈希）
pnpm run build

注意：官方档要求工作树有可解析的 Git 提交（自动取 HEAD 短哈希），构建记录落在 .dsh-build/client-build-environment.json。
