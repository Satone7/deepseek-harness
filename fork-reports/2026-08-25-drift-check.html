2.2 0.16.0 更新内容（按主题归纳）

0.16.0 是一个体量与 0.15.x 整个系列相当的功能大版本，主题归纳如下：

  • 🪟 自由窗口（#354）：任意 tab 可拖出到主会话区成为悬浮窗口（可拖动/缩放/置顶/停靠回侧边栏），floats 随会话持久化；服务语义上 features 新增 'floatWindows'，插件 tab 与 pane 同契约。
  • 📂 模型主动打开（#353）：新增全局设置 agentOpenTools（默认关闭），开启后向模型注入 sidebar_open 工具——模型可在侧边栏打开本地文件/文件夹/网页；非激活会话的打开排队重放。
  • 📝 Markdown 内嵌 HTML + TOC（#360）：README 级块级内嵌 HTML（徽章墙、<details>、表格内 <br/>/<img>）经 DOMPurify 白名单消毒后真实渲染；≥3 标题出现浮动目录大纲。
  • 🌏 19 语言覆盖（#339）：可选 peer @huanlin/dsh-plugin-better-locale，借 DSH 英文槽位生效，zh 下惰性；未安装则整段 no-op。
  • 🌿 Git 多仓库 + linked worktree（#326 #285）：会话 cwd 为工作区容器时显示仓库选择器；worktree 变更发现与按工作树操作事务一致。
  • 🖥️ 浏览器本地回环允许清单（#365）：新设置 browserAllowedLoopback，显式信任的本地开发服务器可导航并获得 allow-same-origin 令牌；服务端 browser.probe 镜像同一允许清单。
  • 📝 编辑器增强：Vue + 28 种 legacy 语言语法高亮（#202）；预览手动刷新 + 保存后自动重载、移除后台轮询（#215 #228）；Markdown 本地/相对图片真实显示（#292）。
  • ➕ 推荐目录新增 ego-browser（#340）。
